## 脱敏规则

- 只使用合成简历、合成候选人和公开示例仓库；不要使用真实姓名、电话、邮箱、住址或真实简历文件名。
- 截图前检查浏览器地址栏、系统通知、项目路径、Git remote、日志和错误面板。
- 对姓名、联系方式、文件名、API URL、token、邮箱等信息做不可逆遮盖；不要用低透明度模糊。
- 截图尺寸统一为 1440×900 或 1600×1000，保持同一暗色主题、浏览器缩放和字体比例。
- 每张图只展示一个模块的关键状态，不把旧版本截图裁剪、翻新或当作 v2 证据。

## README 接入规则

截图完成后，再将本目录中的 v2 资产接入根目录 README。图片必须对应一次真实的当前版本演示，并在 PR/提交说明中注明演示日期与脱敏方式。
