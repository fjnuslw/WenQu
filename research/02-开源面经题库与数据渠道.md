## 0. 结论速览

- 开源仓库去重后约 **1500–3000 道独立 Q&A**、**200–500 条可结构化真实面经**，足够支撑垂直题库冷启动。
- 模型厂商（DeepSeek/Moonshot/MiniMax/智谱/阶跃）**专项面经仓库不存在**——明确的内容空白，可自行填补。
- 合规边界清晰：MIT/Apache 仓库可作答案底稿；无 license 仓库只取题干、自写答案；**小红书/抖音程序化爬取有刑事判例，不碰**；牛客 robots 未禁面经页、linux.do 有公开 JSON API。

## 2. 数据渠道获取方式与合规风险

### 2.1 牛客网（面经第一主阵地）

- 页面结构（实测）：`/discuss/{id}` 详情页仅 6KB JS 壳（客户端渲染）；但**话题聚合页**（如[大模型面经话题页](https://www.nowcoder.com/creation/subject/8603768d1f224b6bbaa48c6b32880a1a)）返回 240KB **服务端渲染 HTML 含正文**——采集应以话题页/面经广场筛选页为种子。
- 公开 API：无社区内容公开 API；`gw-c.nowcoder.com/api/sparta/...` 内部网关属未公开接口，逆向有合规与稳定性风险；[docs.nowcoder.com](https://docs.nowcoder.com/) 仅企业版 ATS 对接。
- **合规信号（实测）**：[robots.txt](https://www.nowcoder.com/robots.txt) 仅 Disallow `/search`、`/nccommon`、`/ab/ab-test-flow`，**discuss/subject/question 页未禁止**，且提供 subject/question/comment 等多个 sitemap——低频、真实 UA、只抓公开页的采集相对有利。
- 反爬：中高——全内容需登录态、有滑块/图形验证码（[实践记录](https://blog.csdn.net/weixin_51328858/article/details/122454307)、[教程](https://zhuanlan.zhihu.com/p/392988299)）。
- 策略：优先用话题聚合页（SSR）+ 面经广场按公司筛选页做种子 URL，低频采集，登录态方案仅限自用账号、抓自己可见内容。

### 2.2 linux.do（Discourse 论坛）

- API 层：Discourse 原生公开 JSON——`/latest.json`（话题列表）、`/t/{id}.json`（全文含 cooked HTML）、`/search.json`、分类/标签接口、RSS（[top.rss 每日抓取案例](https://linux.do/t/topic/2230233)）。匿名按游客权限可用。
- 门槛（关键限制）：要求注册登录使用，Discourse 信任等级 TL0→TL4（[说明](https://linux.do/t/topic/2460)、[新人指南](https://linux.do/t/topic/1665505)）；部分板块对未登录不可见；注册邀请/审核制。游客仅能看到被搜索引擎收录的部分主题页——其中确有大量公开面经帖（[大模型面试资料](https://linux.do/t/topic/1471403)、[面试了十几家 Agent 岗位的面试题](https://linux.do/t/topic/2365650)、[Agent 面试题整理](https://linux.do/t/topic/1791257)、[大模型应用开发面试题库 200 题](https://linux.do/t/topic/2700223)）。
- 策略：`latest.json`/`/t/{id}.json` 游客权限 + RSS 抓公开帖（Agent/RAG 帖质量高）；不登录、不爬受限板块、尊重 rate limit；有 Cloudflare 防护，频率要低。
- 工具参考：[linux-do-analyzer](https://github.com/dext7r/linux-do-analyzer)。

### 2.3 小红书 / 抖音（不建议程序化爬取）

- 技术上：均需签名（XHS `x-s`/`x-s-common`、抖音 `a_bogus`）+ 登录 Cookie；主流开源方案 [NanmiCoder/MediaCrawler](https://github.com/NanmiCoder/MediaCrawler)（63,972 star，**自定义非商业许可，仅限学习**）。
- **法律风险（有真实判例）**：常州案——破解小红书加密算法伪造请求爬取数据、非法获利 653 万元、3 人获刑（[安全内参](https://www.secrss.com/articles/72097)、[常州法院](http://fy.changzhou.gov.cn/index.php?c=phone&a=show&id=13787&catid=40000)）；小红书数据抓取不正当竞争案入选法院 50 件典型知产案例（[天同律所](https://www.tiantonglaw.com/Content/2024/06-27/1022448210.html)）。合法性取决于公开/非公开、是否破坏技术措施、违反 robots、实质性替代、涉个人信息（[光大](https://www.everbrightlaw.com/CN/07/4b3df8779a975b22.aspx)、[金杜](https://www.kingandwood.com/cn/zh/insights/latest-thinking/legal-issues-concerning-web-crawlers.html)、[环球](https://www.glo.com.cn/Content/2022/12-29/1859113198.html)）。
- 替代方案（推荐）：① 浏览器人工浏览+摘录（合规边界最清晰）；② CSDN"多平台面经整理帖"（如[2026 字节大模型岗面经汇总](https://blog.csdn.net/qq_45717425/article/details/160315245)，作者已从小红书/知乎/脉脉汇过去重）；③ 博主常同步发知乎/公众号/牛客，站外留痕；④ 产品化走 UGC 投稿/官方合作。

### 2.4 知乎 / CSDN / 掘金

- 知乎系统性最强：[大模型面试指南专栏](https://www.zhihu.com/column/c_1863115043207507968)（约 100 篇含追问设计）、[包包算法笔记](https://zhuanlan.zhihu.com/p/643560888)、[阿里大模型面试小结](https://zhuanlan.zhihu.com/p/679425549)；反爬（未登录限流），转载需授权。
- CSDN 信息密度高但水文多：[大模型 200 题](https://blog.csdn.net/2301_78285120/article/details/140059146)、[26 秋招系列](https://blog.csdn.net/2401_78285120/article/details/148357671)。
- 掘金偏工程实践，面经专题少：[AI 时代面试讨论](https://juejin.cn/post/7674817329578606619)。
- 共同合规点：**"标题+摘要+出处链接"的聚合索引风险远低于全文抓取**；正文转载需作者授权。

## 3. "大模型版 CodeTop"范式核查

CodeTop 范式 = 公司 × 部门 × 岗位 → 题目 + 出现频率 + 用户爆料。大模型岗位现状：
- 手撕代码（Attention/RoPE/PPO）不属于 LeetCode 题，CodeTop 不覆盖；
- 八股+项目+场景题的高频统计范式**没有成熟对应物**；最接近的是牛客[大模型常考面试题 100 道](https://www.nowcoder.com/exam/test/62119359/interview)、mianshiya 标签-频率题库、wdndev 真实面试题页。
- [社区对面试题网站数据的讨论](https://linux.do/t/topic/372507)侧面证明需求存在。→ **公司×岗位×题目×频率×追问链是明确空白**，用"结构化抽取 + UGC 爆料"冷启动，不依赖爬虫。

## 4. 冷启动评估

- 题库（Q&A）：wdndev + AgentGuide + FAQ_Of_LLM_Interview + WeThinkIn 分享版 + km1994/jackaduma/naginoa + hello-agents 附录 → 去重后 **1,500–3,000 道**，覆盖 LLM 基础/RAG/Agent/推理/微调全栈。
- 真实面经：EasyOffer（9 家公司 LLM 岗）+ Junvate（2026 届实习）+ DolbyUUU（2025 真题）+ 牛客话题页（数百帖）+ linux.do 公开帖（数十帖）→ **200–500 条可结构化面经**。
- Anki：无现成卡组 → 差异化输出功能。

## 6. 建议冷启动路线

1. **第一批（1–2 周，合规干净）**：抓取/清洗 MIT+Apache 仓库 → 统一 schema「题目-答案-标签-难度-来源」→ genanki 顺带产出 Anki 卡组。
2. **第二批（同步）**：牛客公开页合规采集（低频、真实 UA、遵守 robots、SSR 话题页为种子）。
3. **第三批**：linux.do 游客权限 JSON/RSS 抓公开面经帖。
4. **不碰**：小红书/抖音程序化爬取；改人工摘录 + CSDN 汇总帖作线索 + UGC 投稿。
5. **差异化空白**：模型厂商专项题库；"大模型版 CodeTop"频率榜——用 UGC 爆料+真题标注冷启动。
