# 01 竞品调研：是否已有"大模型应用/Agent 求职"垂直平台？

> 调研时间：2026-08-28（网络检索，覆盖国内 13+、国外 10+ 产品）
> 核心问题：① 是否已有专门针对大模型应用开发/Agent 领域设计的求职平台？② 现有产品有什么可借鉴？③ 空白点在哪？

---

## 0. 一句话结论

**没有任何专门面向大模型应用/Agent 开发者的垂直求职平台。**"上传简历让 AI 追问"已有多个竞品，但"上传完整项目代码让 AI 读码拷打"完全空白；"按厂商分类的大模型岗题库"（大模型版 CodeTop）也无结构化产品。这两个空白正是本项目的差异位。

## 1. 三个核心确认问题

### a) 有没有 LLM 应用/Agent 垂直求职平台？——没有
- 国外最接近的是泛 AI 职位板（[aijobs.net](https://aijobs.net/) 约 5 万岗、[Towards AI Jobs](https://jobs.towardsai.net/) 3 万+），只有"岗位聚合"，无题库/面经/模拟面试；面试内容侧最接近 [Exponent](https://www.tryexponent.com/blog/machine-learning-system-design-interview-guide)、[Hello Interview](https://www.hellointerview.com/learn/ml-system-design/in-a-hurry/introduction) 的 ML System Design，但面向传统机器学习，不覆盖 RAG/Agent 编排/工具调用/Prompt 工程栈。
- 国内大模型求职资源全是**内容型/单点工具型**：[小林coding AI 版](https://xiaolinnote.com/ai/)、[代码随想录·大模型面经](https://notes.kamacoder.com/interview/llm/)、[JavaGuide AI 面试指南](https://javaguide.cn/ai/interview-questions/ai-interview-guide.html)、面试鸭 [AI 大模型题库](https://www.mianshiya.com/bank/1906189461556076546)。"垂直岗位 + 按厂商题库 + 面经 + AI 模拟面试"四合一无人做。
- 招聘信息散落在 BOSS 直聘标签、[DeepSeek 官方招聘](https://talent.deepseek.com/)、飞书汇总文档里。

### b) 有没有"上传项目代码+简历，AI 深挖拷打"的产品？——有"传简历"版，无"读代码"版（最大空白）
- 已有（基于简历文本）：面试鸭旗下 [面多多](https://ai.mianshiya.com/) 的"简历押题"（上传简历→预测提问→引申追问）；职悟空（简历+目标 JD 生成"高频追问链路"，主打项目深挖/指标追问）；多面鹅（上传简历生成个性化问题集）。
- 未发现任何产品能**解析完整项目代码仓库**、在真实代码上下文里追问架构决策与技术选型。开源侧最接近的只是演示级雏形（见 research/03）。
- 现实依据：[字节 RAG 岗面经](https://www.nowcoder.com/discuss/759816370367238144) 明确"问题基本从你简历里写的内容深挖"——项目深挖就是真实面试主菜。

### c) 题库按厂商分类的成熟产品？——算法题有，大模型岗没有
- [CodeTop](https://codetop.cc/)：算法题按"公司→部门→岗位→难度→题型"五级筛选 + 频率排序 + 用户爆料，开源对应物 [afatcoder/LeetcodeTop](https://github.com/afatcoder/LeetcodeTop)（20k star）。
- [牛客网](https://www.nowcoder.com/)：面经天然带公司/岗位标签，是最大的按厂商面经池（如 [Agent 开发面经：阿里/蚂蚁/字节](https://www.nowcoder.com/discuss/877151327091027968)）。
- "LLM应用/Agent 岗 × 按厂商的高频题库"（如"字节 Agent 岗高频 50 题"）只有零散帖子（[知乎 20 家公司大模型面经汇总](https://zhuanlan.zhihu.com/p/690801254)），没有结构化产品。

## 4. 市场空白点（按机会大小排序）

1. **"上传完整项目代码库+简历 → AI 读码后逐层拷打"完全空白**——现有产品只解析简历文本；字节等大厂面试恰以项目深挖为主。最强差异点。
2. **没有 LLM 应用/Agent 垂直的一体化平台**——题库、面经、招聘信息三者割裂，四合一无人做。
3. **"大模型岗 × 按厂商题库"缺失**——CodeTop 范式在 LLM/Agent 领域无对标物。
4. **C 端"AI 面试对抗"叙事空白**——B 端 AI 面试官已大规模用于初筛，无人以"帮你通过 AI 面试官"为卖点服务候选人。
5. 表达层反馈（Yoodli 式）+ 中文技术岗场景无人覆盖。

## 5. 值得借鉴的功能清单（直接进入 spec F1–F6 设计）

- 简历押题→预测提问→引申追问链路（面多多/职悟空）→ C 端 AI 面试标配
- 按公司/部门/岗位筛选 + 频率排序 + 用户爆料真题（CodeTop）→ F2 题库组织方式
- 沉浸式完整面试流程 + 多维能力报告（面多多/牛客）→ 报告是付费转化抓手
- 面经 UGC + 公司标签（牛客）→ 冷启动内容池，面经与题库互相引流
- 薪资/offer 爆料（OfferShow）→ 远期社区信任抓手
- 基于个人简历的个性化押题/回答（Final Round）→ 付费意愿最强
- 答案覆盖度洞察（Interview Warmup）→ 免费引流 + 教学
- 终身买断定价（Big Interview）→ 定价参考
- 深度内容营销引流（小林coding/代码随想录）→ 冷启动渠道
- 表达量化分析（Yoodli）→ P2 语音面试的加分项

## 6. 差异化方向（本平台定位依据）

1. **定位收窄到"LLM 应用/Agent 开发者"**：题库、面经、模拟面试官全部围绕 RAG、Agent 编排、Function Calling/MCP、多智能体、微调、评测栈；面试官 prompt 按大厂大模型岗真实追问风格调优（牛客面经显示：阿里系追问多 Agent 协作与 RAG 实现，字节从简历深挖工程链路）。
2. **核心壁垒做"读码拷打"**（F4）：上传 Git repo + 简历 + JD → 静态分析 → 追问树 → "面试官视角的项目漏洞报告"。
3. **CodeTop 式按厂商的 Agent 岗题库**（F2）：面经结构化抽取 + 用户爆料 + 频率榜。
4. **面经聚合走"AI 结构化"路线**（F1）：LLM 把散帖自动抽取成"公司-岗位-轮次-追问"结构化数据，区别于牛客依赖人工发帖。
5. **商业模式参考**：免费（题库基础+1 次体验面试）→ 会员（¥39/月档）→ 按次能量值 → 终身档（¥299–399）。自用 MVP 阶段不涉及，仅作远期预留。
