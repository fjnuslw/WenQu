## 2. 方向共识与阶段切分

交叉验证 linux.do 一线经验 + 中文站阶段划分 + 现有 spec §3/§4 的 12 标签族，得到四条线的定位与阶段。

### 2.1 四条线的差异化定位（避免做成同一件事的四个副本）

| 线 | 一句话定位 | 核心问题 | 不覆盖什么 |
|---|---|---|---|
| **大模型应用** | 用现成模型把业务跑通并验证效果 | 怎么让 LLM 稳定、可控、可评测地干活 | 不训练模型、不写算子 |
| **大模型算法** | 懂模型本身，能改能训能优化 | 模型为什么这样、怎么训得更好更省 | 不负责上线运维 |
| **大模型开发** | 把模型和 Agent 做成可运维的生产系统 | 怎么服务化、怎么扛量、怎么控成本 | 不做算法创新 |
| **手撕算法** | 大厂面试的硬门槛，限时写对讲清 | 见题有思路、写得出、讲得清复杂度 | 不覆盖系统设计（另设选修） |

> 三者（应用/算法/开发）共用「Python + LLM 基础」这一层，但**共用层单独抽出来做前置**，避免三条线各写一遍。

### 2.2 阶段切分（每条线 5–6 阶段，每阶段 3–6 节点）

**共用前置（L0）**：Python 工程能力 · Linux/Git/Docker · LLM 通识（token/上下文/温度/幻觉）

**L1 大模型应用**
1. 调用与提示（API 直连、结构化输出、Few-shot/CoT）
2. 工具调用与 Function Calling（schema 设计、错误处理、多轮工具循环）
3. RAG 全链路（解析 → 切分 → 向量/混合检索 → 重排 → 生成约束 → 评测闭环）
4. Agent 与编排（ReAct、LangGraph 状态机、记忆、人审）
5. 多智能体与协议（多 Agent 协作模式、MCP、A2A 生态）
6. 评测与上线（评测集、可观测、成本/延迟治理）

**L2 大模型算法**
1. 数学与深度学习基础（张量/梯度/反向传播、优化器）
2. Transformer 原理与从零实现（注意力、位置编码、手写 GPT）
3. 预训练与 Scaling（数据配方、tokenizer、Scaling Law、Chinchilla）
4. 高效微调（LoRA/QLoRA、PEFT 全家桶）
5. 对齐与后训练（SFT、RLHF、DPO、GRPO、推理模型）
6. 推理优化与论文复现（量化、KV Cache、PagedAttention、FlashAttention、复现报告）

**L3 大模型开发**
1. 服务端工程（FastAPI、异步、流式 SSE、并发与超时）
2. 推理服务化（vLLM / SGLang / TGI / Triton、批处理与调度）
3. 容器与云（Docker、GPU 环境、K8s 基础、成本模型）
4. 分布式训练（DDP/FSDP、DeepSpeed ZeRO、Accelerate）
5. LLMOps（实验追踪、数据版本、评测流水线、灰度与回滚）
6. 可观测与治理（Tracing、Prompt 版本、护栏与权限、成本看板）

**L4 手撕算法（大厂向）**
1. 数据结构与复杂度（数组/链表/栈队列/哈希/树/堆/前缀和差分）
2. 基础算法模板（二分、双指针、滑动窗口、排序、BFS/DFS）
3. 高频专题（动态规划、回溯、图论、贪心、字符串）
4. 题型清单攻坚（Hot 100 → 剑指 Offer → 厂频榜）
5. 面试仿真（限时手写、白板讲解、边界用例、follow-up）
6. 复盘与错题回炉（错题回流 SM-2，与 F6 打通）

### 2.3 从调研直接推导出的设计约束

- **D1｜节点必须有验收标准**，否则与网上的「资源收藏夹」无差别。每个节点写「完成判据」（跑通什么 / 刷完几题 / 写出什么）。
- **D2｜资源必须带证据字段**：star、license、最近推送、链接可用性，且**周期性复检**（GitHub API + HTTP 探测，脚本已在 `search/_raw/`）。
- **D3｜License 门禁沿用 spec §10**：GPL/AGPL 仓库**禁入**（本次已发现 `firecrawl` AGPL、`khoj` AGPL、`Fosowl/agenticSeek` GPL、`ashishps1/awesome-leetcode-resources` GPL、`xlite-dev/Awesome-LLM-Inference` GPL，全部排除）。
- **D4｜中文优先、英文一手并存**：用户为中文母语硕士求职者，中文教程走主线，论文/官方文档保留英文原文。
- **D5｜必学/选修/参考三级**，控制单条线必学资源在 25–35 条，避免劝退。
- **D6｜实战节点必须含「评测 + badcase 闭环」**（来自 linux.do 帖 2174720）。
- **D7｜与既有模块打通而非另起炉灶**：节点 → 题库题目（F2）/ 复习卡（F6）/ 项目拷打（F4），路径本身不重复造知识库。
